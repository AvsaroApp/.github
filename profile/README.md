# Avsaro

Avsaro connects customers with trusted local service providers. Discover services, book appointments, and manage your bookings in one place.

## Our repositories

- [Avsaro](https://github.com/AvsaroApp/Avsaro) — Avsaro’s main application
- [AvsaroMobileApp](https://github.com/AvsaroApp/AvsaroMobileApp) — Avsaro for mobile

We’re building tools to make finding and managing local services simpler.
